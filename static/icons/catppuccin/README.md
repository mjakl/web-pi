# Catppuccin file icons

This directory contains a selected subset of
[Catppuccin Icons for VSCode](https://github.com/catppuccin/vscode-icons),
version `v1.26.0` (`b6915da9f6889b683a110aa747de96c2820a537d`).

- `latte/` holds the icons, from the Latte flavour.
- web-pi uses the SVG alpha channel as a mask and applies `var(--text-dim)`, so
  only the shapes count: the rendered icons remain monochrome, and the same
  files serve both themes.
